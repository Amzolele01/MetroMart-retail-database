# Sales Dataset Profile

## 1. Dataset Overview

The `sales_2023_2025` dataset contains detailed sales transaction records covering the period indicated by its filename. It captures transaction dates, store and employee references, product information, quantities, prices, discounts, and recorded transaction totals.

The dataset was profiled to understand its structure, completeness, uniqueness, transaction distribution, and the characteristics of its numerical and reference fields.

| Attribute | Details |
|---|---|
| Dataset | `sales_2023_2025` |
| Total records | 100,000 |
| Total fields | 9 |
| Profiling tool | Google Sheets |

## 3. Initial Profiling Observations

### 3.1 Transaction Identifier (`transaction_id`)

- All 100,000 records contain a transaction identifier.
- No missing values were identified.
- All 100,000 identifiers are unique.

**Observation:** Every sales record has a distinct transaction identifier. Based on the initial profiling results, `transaction_id` is a potential primary key.

### 3.2 Transaction Date (`transaction_date`)

- All 100,000 records contain a transaction date.
- No missing values were identified.
- The field contains 99,956 unique values.
- There are 44 repeated occurrences beyond the first occurrence.

**Observation:** The transaction date field contains repeated date-time values. Multiple sales records can share the same recorded timestamp, so repeated values do not necessarily indicate duplicate transactions.

The field was recorded as a string during initial profiling. Its appropriate date-time representation will be considered during database preparation.

### 3.3 Store Reference (`store_id`)

- All 100,000 records contain a store reference.
- No missing values were identified.
- Five unique store identifiers were recorded.

| Store ID | Sales Records |
|---|---:|
| S001 | 20,028 |
| S002 | 19,887 |
| S003 | 19,938 |
| S004 | 20,199 |
| S005 | 19,948 |
| **Total** | **100,000** |

**Observation:** All five store identifiers are represented in the sales dataset. The distribution of sales records across the stores is relatively balanced, with S004 having the highest record count.

### 3.4 Employee Reference (`employee_id`)

- All 100,000 records contain an employee reference.
- No missing values were identified.
- Sixty unique employee identifiers were recorded.
- The number of sales records associated with individual employees varies.

The initial profiling identified:

- E015 as having the highest recorded count, with 4,059 sales records.
- E060 as having the lowest recorded count, with 955 sales records.

**Observation:** All 60 employee identifiers are represented in the sales dataset. The number of associated sales records varies considerably between employees.

### 3.5 Product Reference (`product_id`)

- All 100,000 records contain a product reference.
- No missing values were identified.
- Twenty unique product identifiers were recorded.
- All 20 products are represented in the sales dataset.
- A trailing space was observed in the representation of product identifier `P011`.

**Observation:** The sales dataset references all 20 products in the product catalogue. The trailing space associated with `P011` is recorded as a potential formatting inconsistency.

### 3.6 Quantity (`quantity`)

- All 100,000 records contain a quantity value.
- No missing values were identified.
- Eight unique quantity values were recorded.

**Observation:** The quantity field contains eight distinct values across the sales records. The field was recorded as an integer during initial profiling.

### 3.7 Unit Price (`unit_price`)

- All 100,000 records contain a unit price.
- No missing values were identified.
- Seventeen unique price values were recorded.

**Observation:** The sales dataset contains 17 distinct unit prices. This matches the number of unique price values identified in the products dataset during its initial profiling.

The relationship between recorded sales prices and product catalogue prices can be examined during subsequent investigation.

### 3.8 Discount Percentage (`discount_pct`)

- All 100,000 records contain a discount value.
- No missing values were identified.
- Five unique values were recorded.

**Observation:** The discount field contains five distinct values and was recorded as a decimal during initial profiling.

### 3.9 Total Amount (`total_amount`)

- All 100,000 records contain a recorded total amount.
- No missing values were identified.
- The field contains 339 unique values.

**Observation:** The recorded transaction totals vary across the dataset, with 339 distinct values identified. The field was recorded as a decimal during initial profiling.

## 4. Profiling Summary

The initial profiling established the following characteristics:

- The dataset contains 100,000 records across nine fields.
- All transaction identifiers are populated and unique.
- Transaction dates contain 44 repeated occurrences beyond the first occurrence.
- All five store identifiers and all 60 employee identifiers are represented.
- All 20 product identifiers are represented in the sales records.
- A trailing space was observed in the representation of product identifier `P011`.
- Quantity values contain eight unique values.
- Unit prices contain 17 unique values, matching the distinct price count in the products dataset.
- Discount percentages contain five unique values.
- Recorded transaction totals contain 339 unique values.
- No missing values were identified in any of the nine fields.

## 5. Source Structure Note

The original business data dictionary includes a `customer_id` field under sales. However, the actual supplied `sales_2023_2025` source contains nine fields and does not include `customer_id`.

This profile therefore reflects the actual source structure. The discrepancy between the original dictionary and the supplied sales dataset is documented in the initial data dictionary.

## 6. Profiling Conclusion

The `sales_2023_2025` dataset is the largest source dataset in the project, containing 100,000 records across nine fields.

All fields contain populated values. The transaction identifiers are unique, while the reference fields cover the five stores, 60 employees, and 20 products represented in the other source datasets.

The initial profiling also identified repeated transaction timestamps, a product identifier formatting variation, and distinct value distributions across the quantity, pricing, discount, and total amount fields.

These findings provide an initial understanding of the sales dataset. Further investigation into transaction values, date-time handling, reference consistency, and the observed formatting variation is handled separately during the data quality investigation stage.

No changes were made to the original source data during profiling.
