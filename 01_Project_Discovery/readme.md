# 01 — Project Discovery

## 1. Overview

Project Discovery establishes the foundation for the MetroMart Retail Database Project.

This phase focuses on understanding the client's business context, identifying the problem to be addressed, reviewing the supplied source materials, establishing project requirements and defining the proposed approach to the solution.

It provides the direction and documentation needed before proceeding with detailed data investigation, transformation and database development.

## 2. Phase Objectives

The objectives of this phase are to:

- Understand the client's business background and reporting challenges.
- Review the original client brief and business requirements.
- Identify the available operational datasets and supporting reference files.
- Establish the project scope, objectives and expected deliverables.
- Identify initial assumptions, constraints and potential risks.
- Define the proposed data-handling approach and project methodology.
- Establish a clear foundation for subsequent project phases.

## 4. Approach

The project follows an evidence-based discovery approach.

Original client materials are reviewed first to understand the business requirements and expectations. Available datasets and reference files are then examined to establish the project's data landscape and inform subsequent investigation activities.

Project decisions, assumptions and unresolved questions are documented rather than treated as confirmed facts without supporting evidence.

## 5. Data Handling Principles

- Preserve original client-provided source files.
- Perform investigation and transformation on separate working copies.
- Document important findings and decisions.
- Maintain source traceability wherever practical.
- Avoid making assumptions about data structures or business rules without validation.

## 6. Expected Outputs

This phase will establish:

- Documented project background and problem statement.
- Defined project purpose and objectives.
- Business requirements and analytical questions.
- Project scope and boundaries.
- Source data inventory and proposed data architecture.
- Technology stack and project methodology.
- Documented assumptions, constraints and risks.
- Defined project deliverables and acceptance criteria.

## 7. Relationship to Subsequent Phases

Project Discovery provides the foundation for the remaining project activities.

The requirements, scope, source inventory and proposed approach established here guide the subsequent data investigation, cleaning, database design, implementation and analytical reporting work.
