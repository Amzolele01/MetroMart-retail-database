# Client Brief

This directory contains the original project-definition documents supplied by the MetroMart Retail Group client.

These documents establish the business context, project expectations, business requirements and initial field descriptions. They serve as the primary reference for understanding the client's request.

## Source Documents

| File | Description |
|---|---|
| [Client_Brief.pdf](./Client_Brief.pdf) | Describes MetroMart's business background, the data-management problem, the client request, expected outcome and initial business questions. |
| [Business_Requirements.pdf](./Business_Requirements.pdf) | Defines the ten business requirements (BR-01 to BR-10) that the project is expected to address. |
| [Data_Dictionary_Initial.xlsx](./Data_Dictionary_Initial.xlsx) | Provides the initial field descriptions supplied for the customer and sales datasets. |

## Data Handling

These documents are preserved in their original form. Any interpretations, revisions or additional documentation developed during the project should be maintained separately.
