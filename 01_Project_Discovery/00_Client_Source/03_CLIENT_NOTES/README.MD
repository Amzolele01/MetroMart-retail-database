# Client Notes

This directory contains informal notes and introductory instructions supplied as part of the MetroMart Retail Group client package.

These documents provide additional context for understanding the source data and the client's expectations for handling the project.

## Source Documents

| File | Description |
|---|---|
| [Previous_System_Notes.txt](./Previous_System_Notes.txt) | Contains historical information and potential data-related concerns, including previous POS systems, store-code changes, customer duplicates, returns handling and sales-total calculations. |
| [README_FIRST.txt](./README_FIRST.txt) | Provides the client's recommended starting instructions and data-handling guidelines for the project. |

## Important Considerations

The previous system notes are informal and may be incomplete. Their contents should be treated as investigation clues rather than confirmed facts.

The introductory instructions establish important handling principles:

- Do not immediately build the database.
- Inspect and investigate the supplied source files.
- Do not modify original raw data.
- Use separate working copies for cleaning and transformation.
- Document discoveries, assumptions and decisions.

## Usage

These notes guide the initial discovery process and help establish the principles followed throughout the project.
