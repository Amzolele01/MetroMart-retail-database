# Raw Data

This directory contains the seven original operational datasets supplied as part of the MetroMart Retail Group client package.

These datasets represent the raw source data used throughout the project. They are the starting point for data discovery, profiling, quality investigation, cleaning and transformation.

## Source Files

| File | Description |
|---|---|
| [customer_export_legacy.csv](./customer_export_legacy.csv) | Legacy customer records from an earlier customer-data export. |
| [customers.csv](./customers.csv) | Customer records from the supplied customer dataset. |
| [employees.csv](./employees.csv) | Employee records, including employee identifiers, names, store assignments and roles. |
| [products.xlsx](./products.xlsx) | Product catalogue containing product details, categories and pricing. |
| [returns.csv](./returns.csv) | Records of returned sales, including transaction and product references. |
| [sales_2023_2025.csv](./sales_2023_2025.csv) | Sales transaction records covering 2023–2025. |
| [stores.csv](./stores.csv) | Store records containing store identifiers, names and locations. |

## Data Preservation Rules

- Original source files must remain unchanged.
- Data investigation and cleaning must use separate working copies.
- Any transformations must be documented.
- Source traceability must be maintained wherever practical.

## Usage

These datasets are used as the primary operational data sources for the MetroMart Retail Database Project.
