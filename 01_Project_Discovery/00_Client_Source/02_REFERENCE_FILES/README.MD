# Reference Files

This directory contains supporting reference files supplied with the MetroMart Retail Group client package.

These files provide additional reference information for interpreting and validating selected operational datasets.

## Reference Documents

| File | Description |
|---|---|
| [product_categories.xlsx](./product_categories.xlsx) | Contains the supplied product category reference information used when investigating product categories and subcategories. |
| [store_codes.csv](./store_codes.csv) | Contains store code reference information used when investigating store identifiers and historical store-code mappings. |

## Data Handling

- Preserve the original reference files without modification.
- Use separate working copies when additional processing is required.
- Document how reference information is used during data investigation and transformation.

## Usage

These files support the investigation and interpretation of the operational datasets. They should not automatically be treated as authoritative where inconsistencies or ambiguities require further validation.
